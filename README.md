# مَسار v0.2

نسخة Mobile-first مطوّرة لأداة إحالات الطلاب بين المعلم والوكيل، مع استعداد كامل للعمل بحسابات حقيقية وقاعدة بيانات مشتركة عبر Supabase.

## الجديد في v0.2

- شاشة دخول حقيقية بالبريد وكلمة المرور عند ربط Supabase.
- أدوار فعلية: **معلم / وكيل / مدير**.
- قاعدة بيانات مشتركة بين الأجهزة.
- المعلم يرسل الإحالة من جهازه.
- الوكيل يستقبلها ويكتب الرد من جهاز آخر.
- رد الوكيل يظهر للمعلم مع تحديث Realtime.
- المعلم يغلق المعاملة بعد الاطلاع على الرد.
- صلاحيات RLS تمنع المعلم من مشاهدة إحالات معلمين آخرين.
- المدير يضيف الصفوف والفصول والطلاب.
- نسخة معاينة محلية تعمل حتى قبل ربط Supabase.
- PWA قابلة للتثبيت على الجوال.

## 1) تجربة النسخة مباشرة بدون قاعدة بيانات

شغّل المجلد عبر خادم محلي:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

سيظهر زر **دخول نسخة المعاينة**. من داخل التطبيق اضغط اسم الحساب أعلى الشاشة للتبديل بين المعلم والوكيل والمدير.

## 2) تفعيل الحسابات الحقيقية وقاعدة البيانات

### أ. إنشاء مشروع Supabase

1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح **SQL Editor**.
3. انسخ محتوى الملف `supabase-setup.sql` ونفّذه كاملًا.

### ب. إضافة بيانات الربط

من Supabase افتح **Project Settings > API** ثم انسخ:

- Project URL
- Anon / Publishable Key

ضعهما داخل `config.js`:

```js
window.MASAR_CONFIG = {
  supabaseUrl: 'https://YOUR-PROJECT.supabase.co',
  supabaseAnonKey: 'YOUR-ANON-KEY'
};
```

> الـ Anon Key مخصص أصلًا للاستخدام في الواجهة الأمامية، والحماية الفعلية هنا تعتمد على سياسات RLS الموجودة في ملف SQL.

### ج. إنشاء حسابات المدرسة

من Supabase:

**Authentication > Users > Add user**

أنشئ حسابات المعلمين والوكيل والمدير بالبريد وكلمة المرور. كل حساب جديد سيُنشأ افتراضيًا بدور `teacher`.

بعدها غيّر دور المدير والوكيل من SQL Editor، مثال:

```sql
update public.profiles p
set role='admin', full_name='مدير المدرسة'
from auth.users u
where p.id=u.id and u.email='admin@school.sa';

update public.profiles p
set role='vice', full_name='وكيل شؤون الطلاب'
from auth.users u
where p.id=u.id and u.email='vice@school.sa';
```

## 3) أول تشغيل فعلي

1. سجّل الدخول بحساب **المدير**.
2. افتح **الطلاب**.
3. أضف الصفوف والفصول.
4. أضف الطلاب داخل كل فصل.
5. سجّل الخروج.
6. ادخل بحساب **المعلم** وأنشئ إحالة.
7. افتح التطبيق في جهاز آخر بحساب **الوكيل** ورد على الإحالة.
8. سيظهر الرد في حساب المعلم، ثم يستطيع إغلاق المعاملة.

## الملفات الرئيسية

- `index.html` — الواجهة.
- `styles.css` — الهوية والتصميم الفاخر.
- `app.js` — التطبيق، المصادقة، الصلاحيات، Realtime.
- `config.js` — بيانات ربط Supabase.
- `supabase-setup.sql` — الجداول والسياسات والتريجرات.
- `manifest.webmanifest` + `service-worker.js` — PWA.
